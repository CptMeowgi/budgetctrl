# Phase 2 — Forecasting + Click-to-filter — Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** Add a linear variable-spend forecast (chart line + stat card) that projects current velocity to month-end, and make the category donut + monthly bars on the Dashboard clickable for navigation into filtered/drilled-down views.

**Architecture:** All changes land in `src/App.jsx` (single-file React app). `variableDaily` gains forecast outputs (`todayDay`, `actualToday`, `projectedVariable`) and augments data points with a `projected` key. `VariableSpendChart` renders a dashed amber forecast line when active. A new conditional "Projected" stat card joins `statsRow` as a 5th card. A new `expenseFilter` state drives a filter chip in the Expenses tab, wired to `CategoryDonut`'s new `onSliceClick` prop. `MonthlyBarChart` gains `curKey` and `onBarClick` props so past-month bars navigate into History detail.

**Tech Stack:** React 19, Vite, Recharts, localStorage. No tests — verification via Claude Preview MCP (screenshots + `preview_eval` + `preview_console_logs`).

**Reference design doc:** `docs/plans/2026-04-09-phase2-design.md`

**Verification note:** This repo has no test framework. Every task ends with a preview check. Server runs via `.claude/launch.json` (`budget-ctrl`, port 5173). Not a git repo — no commits.

## Task 1: Extend `variableDaily` with forecast outputs

**Files:**
- Modify: `src/App.jsx` — the `variableDaily` function (grep `function variableDaily`)

**Step 1: Locate and read the current helper**

Read the full body of `function variableDaily(month, key, baseIncome, credits, savingsPct)`. It currently returns `{ data, variableBudget, fixed }`.

**Step 2: Insert forecast computation before the `return` statement**

Right after the existing `for (let day = 1; day <= daysInMonth; day++) { ... }` loop finishes building `out[]`, and before `return { data: out, variableBudget, fixed };`, insert:

```js
const today = new Date();
const curKeyNow = `${today.getFullYear()}-${String(today.getMonth() + 1).padStart(2, "0")}`;
const isCurrentMonth = key === curKeyNow;
const todayDay = isCurrentMonth ? Math.min(today.getDate(), daysInMonth) : 0;
const actualToday = todayDay > 0 ? out[todayDay - 1].actual : 0;
const projectedVariable = todayDay >= 5
  ? (actualToday / todayDay) * daysInMonth
  : null;

if (projectedVariable != null) {
  for (let i = 0; i < out.length; i++) {
    const day = i + 1;
    if (day < todayDay) {
      out[i].projected = null;
    } else if (day === todayDay) {
      out[i].projected = actualToday;
    } else {
      const t = (day - todayDay) / (daysInMonth - todayDay);
      out[i].projected = actualToday + (projectedVariable - actualToday) * t;
    }
  }
}
```

**Step 3: Update the return statement**

Replace:
```js
return { data: out, variableBudget, fixed };
```

with:

```js
return { data: out, variableBudget, fixed, todayDay, actualToday, projectedVariable };
```
